STOCKPYME 1.5 — IDIOMAS, MONEDAS, PLAN BÁSICO Y PLAN NEGOCIO
=================================================

1. Copia todo el contenido de esta carpeta StockPyme dentro de tu proyecto
   (C:\dev\stock_pyme\stock_pyme) y acepta "Reemplazar los archivos".

   Este zip NO trae lib\firebase_options.dart ni pubspec.lock a propósito:
   así se mantiene tu configuración de Firebase. No los borres.

2. En la terminal de VS Code, dentro del proyecto:

     flutter pub get
     git add .
     git commit -m "v1.5: idiomas, monedas y plan semestral"
     git push

3. GitHub Actions genera el APK y el programa de Windows solos.

4. Servidor de pagos: actualiza el repositorio Stockpyme-pagos con el zip
   Stockpyme-pagos_negocio.zip (Plan Básico y Plan Negocio).
   Hazlo ANTES de publicar esta versión de la app.

5. Firebase: abre Firestore → Reglas, pega el contenido nuevo de
   firestore.rules y toca Publicar (se agregó el campo manualProTier).
